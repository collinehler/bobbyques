# Bobby-Ques website

The website for Bobby-Ques, 506 Argyle St, Waterloo, Iowa.

## Making a change from your phone

1. In Safari, open this repository on github.com and tap the file you want to change. Almost everything is in `index.html`.
2. Tap the pencil icon (Edit). If you don't see it, tap the three dots and choose Edit file.
3. Change only the words or numbers. Each section of `index.html` starts with a short note that explains how.
4. Tap **Commit changes**. The site updates a few minutes later.

## What's where

- `index.html`: everything people read on the site (menu and prices, hours, about us, catering, address)
- `styles.css`: colors, fonts and layout
- `script.js`: the open/closed sign, which reads the Hours table in `index.html`
- `images`: the logo and icons
- `fonts`: the fonts
